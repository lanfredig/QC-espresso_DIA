DIA LFQ Benchmark Analysis

Jackson Gabriel Miyamoto

2026-10-31

Overview

This workflow evaluates quantitative performance of DIA proteomics data using a mixed-species benchmark containing Human, Saccharomyces cerevisiae (Yeast), and Escherichia coli proteins with predefined abundance ratios between experimental conditions A and B.

The analysis evaluates:

  • protein-level quantitative precision;
  • accuracy of measured fold changes;
  • deviation from theoretical abundance ratios;
  • abundance-dependent quantitative performance; and
  • species-specific quantitative behavior.

The workflow operates on the protein-group quantitative matrix generated by DIA-NN (report.pg_matrix.tsv).

DIA-NN protein-group matrices contain normalised protein-group quantities. Protein groups are therefore treated as the primary quantitative entities in this analysis.

Methods

Experimental design

The expected species-specific abundance ratios are:

Species Condition A Condition B Expected B/A Expected log2(B/A)
Human 65 65 1.00 0
Yeast 15 30 2.00 1
E. coli 20 5 0.25 -2

All fold changes are calculated as:

\[ \log_2(B/A) = \log_2\left(\frac{\bar{B}}{\bar{A}}\right) \]

where \(\bar{A}\) and \(\bar{B}\) are the arithmetic mean protein-group quantities across the three technical/biological replicates in conditions A and B, respectively.

Completeness Filtering

Protein groups are retained only when quantitative values are available in all three replicates of both conditions.

df <- df %>%
  mutate(
    nA = rowSums(!is.na(across(all_of(A_cols)))),
    nB = rowSums(!is.na(across(all_of(B_cols)))))

completeness_summary <- df %>%
  summarise(total = n(),
    complete = sum(nA == length(A_cols) & nB == length(B_cols)),
    incomplete = sum(!(nA == length(A_cols) & nB == length(B_cols))))

Protein-Level Metrics

metrics <- df %>%
  rowwise() %>%
  mutate(
    mean_A = mean(c_across(all_of(A_cols)), na.rm = TRUE),
    mean_B = mean(c_across(all_of(B_cols)), na.rm = TRUE),

    sd_A = sd(c_across(all_of(A_cols)), na.rm = TRUE),
    sd_B = sd(c_across(all_of(B_cols)), na.rm = TRUE),

    cv_A = 100 * sd_A / mean_A,
    cv_B = 100 * sd_B / mean_B,

    mean_CV = mean(c(cv_A, cv_B), na.rm = TRUE),

    abundance = log2((mean_A + mean_B) / 2),

    observed_logFC = if_else(
      mean_A > 0 & mean_B > 0,
      log2(mean_B / mean_A),
      NA_real_
    )
  ) %>%
  ungroup()

Summary Metrics

Fold-Change Accuracy

df_metrics <- metrics %>%
  left_join(sampleComposition %>%
      select(species, expected_logFC), by = "species") %>%
  mutate(deviation = observed_logFC - expected_logFC) 

fc_metrics <- df_metrics %>%
  filter(is.finite(deviation)) %>%
  group_by(species) %>%
  summarise(
    proteins = n(),
    median_logFC = median(observed_logFC, na.rm = TRUE),
    mean_deviation = mean(deviation, na.rm = TRUE),
    sd_error = sd(deviation, na.rm = TRUE),
    median_abs_error = median(abs(deviation), na.rm = TRUE),
    RMSE = sqrt(mean(deviation^2, na.rm = TRUE)),
    .groups = "drop")
